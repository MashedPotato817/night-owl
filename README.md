# 夜猫子 BBS · 今晚几点睡？

一个深蓝夜空与 Windows 95 风格的熬夜投票 demo。选择今晚睡觉时间，看看示例百分比统计，领取一张夜猫子身份卡。

## 启动

需要 Node.js 18 或更新版本，无需安装依赖：

```sh
npm run dev
```

浏览器打开 http://127.0.0.1:4173 。也可以直接打开 `index.html`，但本地记录以 HTTP 启动的浏览器环境为准。

## 功能

- 五档睡觉时间，原生单选框与键盘操作。
- 投票成功、百分比条、专属身份及趣味短评。
- 本地记录、刷新恢复、修改、确认撤回和多标签页同步。
- 论坛公告、晚安便签、晚安弹窗、实时本机时钟。
- 手机单栏适配，装饰使用纯 CSS，无外部资源请求。

统计明确为 **1,024 份固定示例票 + 本浏览器选票**。localStorage 不提供真实多人投票、防刷或跨设备同步。身份短评仅供娱乐。
