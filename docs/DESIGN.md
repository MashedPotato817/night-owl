# 夜猫子 BBS · 产品与交互设计

已逐一通读仓库最初的全部文件：`AGENTS.md`、`keyword.md`、`.agents/commit-message/SKILL.md`。关键词为「用复古网页风的方式，做一个关于熬夜的投票器」。项目原先没有代码、依赖或 Git 仓库。

后续已通读用户指定的 `docs/活动网页调研.md`，以其中三项作品的观察与最新用户要求作为最终方案依据。

## 2. 产品定义

名称：夜猫子 BBS / NIGHT OWL BBS。标语：白天属于世界，夜晚留给自己。

目标用户：夜间刷到页面、想用一次轻量投票表达当下状态的年轻用户；也适合活动评审在一分钟内体验完整流程。

核心任务：选择今晚准备睡觉的时间 → 提交 → 看到结果与自己的选择 → 可修改或撤回。

本次交付为工作区内可运行的成熟前端 demo。统计由固定示例票数与本浏览器一票组成，不连接真实多人服务。页面显著标注示例数据，避免制造真实在线人数、真实社区留言或虚假热度。调研中建议的可选第二题暂不加入，优先确保睡觉时间投票的完整体验。

## 3. 信息架构

1. 顶部品牌、投票/统计导航、关于入口与本机时钟。
2. 桌面页头：栏目编号、醒目标题、简短情绪文案、像素月亮插图。
3. 左侧主窗口：浏览器式标题栏、地址栏、投票题目、五个单选项、提交操作、状态反馈。
4. 右侧辅助窗口：夜猫子身份卡、论坛公告栏、晚安便签。
5. 底部任务栏：当前应用、数据模式、本机时间。

## 4. 视觉系统

- 桌面：深蓝夜空 `#101c42`，细网格、有限星点；不使用外部照片。
- 内容纸张：米白 `#f7f3e5`；窗框：经典灰 `#cecec7`。
- 主强调：月光黄 `#f2da89`；标题栏：深蓝 `#243b83`；正文：`#242b46`。
- 硬边框、双线边沿、4px 实体阴影，取代大圆角与模糊光晕。
- 中文使用系统无衬线保证可读；英文编号与时间使用系统等宽字体。主标题用粗体字，与小型英文栏目形成层级。
- 桌面内容最大宽 1160px，主辅栏约 2:1；小于 800px 单栏，小于 480px 缩紧间距，保持完整点击区域。

## 5. 交互与状态

| 状态 | 行为与反馈 |
| --- | --- |
| 初始 | 无默认选项；提交按钮禁用；允许直接浏览统计 |
| 已选 | 卡片高亮，提交按钮启用；显示选项说明 |
| 提交成功 | 保存本机一票及时间，展示统计；身份卡显示对应称号、计划时间与趣味短评；读屏提示成功 |
| 已投票后刷新 | 恢复选票与结果，防止刷新重复累计 |
| 修改投票 | 回到表单并保留选择，提交时替换原票，票数最多增加一票 |
| 撤回 | 通过确认对话框撤销本机选票，恢复固定示例统计 |
| 无本机存储权限 | 保留当前会话体验，明确提示刷新后记录可能丢失 |
| 本机数据损坏 | 丢弃非法记录，安全恢复初始状态 |
| 多标签页 | storage 事件同步选票，避免标签页显示不一致 |

统计按固定选项顺序展示，每项同时提供票数、百分比与条形图。所有百分比使用最大余数法分配，合计 100%。主次页面导航使用按钮 pressed 状态，非伪装的无效链接。关于、撤回与晚安提示使用原生 dialog，支持 Esc 关闭。

## 6. 内容

五个互斥的睡觉时间：23 点前、23:00–00:00、00:00–01:00、01:00–02:00、02:00 以后。对应「好梦先行官」「午夜守门员」「月光收藏家」「灵感值班员」「银河巡夜员」及固定趣味短评。身份只用于娱乐，不改变计票。语气轻松但不羞辱用户；不提供未经证实的医疗建议。晚安便签是陪伴式文案，不鼓励熬夜。

## 7. 技术与边界

原生 HTML/CSS/JavaScript，零运行依赖；Node 静态服务支持本地预览，亦可直接打开 HTML。localStorage 仅保存选项 ID、投票时间与版本号。内容无用户输入注入点，无第三方追踪、字体或图片请求。

本期不含账户、后端、真实多人计票、社交分享服务、实时在线人数。正式上线多人版本需增加服务端原子计票、幂等请求、反滥用策略与隐私说明。

## 8. 验收标准

- 首屏可明确识别熬夜主题、复古风格与主要投票入口。
- 五项单选、提交、看结果、改票、撤回、刷新恢复形成闭环。
- 示例票数总和一致，本机只贡献一票，改票不增加总量。
- 375px 手机和 1440px 桌面无横向溢出，键盘可完成流程。
- 无外部运行依赖，JavaScript 语法检查与核心计票测试通过；浏览器验证结果记录于交付说明。
