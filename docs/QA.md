# Demo 验证记录

验证日期：2026-10-24。环境：本机 Node.js、Codex 内置浏览器，通过 `http://127.0.0.1:4173` 访问。

## 自动检查

- `npm run check`：app.js、poll-core.js、server.cjs 语法通过。
- `npm test`：3 项核心规则测试通过；覆盖示例总数、五种选择、重复计算、改票总量、撤回与非法记录。
- `git diff --cached --check`：提交前检查空白错误。

## 浏览器实测

| 场景 | 观察结果 |
| --- | --- |
| 初始状态 | 五个选项无默认值，提交按钮禁用 |
| 选择后提交 | 按钮启用，结果显示 1,025 票、当前选择与对应身份短评 |
| 刷新页面 | 保留原选项、投票时间和统计，不新增选票 |
| 修改选择 | 原选项减一，新选项加一，总数仍为 1,025 |
| 取消撤回 | 原票与身份保留 |
| 确认撤回后刷新 | 回到未投票状态，选项清空、提交禁用 |
| 键盘 | 方向键切换单选，Tab 到提交，Enter 完成投票；焦点移至身份反馈 |
| Review 键盘回归 | 刷新后首次 Tab 显示跳转链接；Enter 跳转 `#main` 且焦点落入正文 |
| 375 × 812 手机 | 单栏，选项完整，结果区顶部展示身份；文档宽度不超过视口 |
| 1440 × 1080 桌面 | 主投票和辅助信息双栏；文档宽度不超过视口 |
| 控制台 | 本次检查未发现 error 或 warn |
