## 发现与处理

### [P2] 跳过导航链接无法通过键盘访问（已修复）

原样式 `.skip { visibility:hidden }` 使链接不参与 Tab 导航，因此 `.skip:focus` 无法从键盘触发。改为通过位移将链接移出屏幕，获得焦点时显示；正文 `main` 添加 `tabindex="-1"`，让锚点跳转明确落到正文。

浏览器回归：刷新后按 Tab，首个焦点为「跳到投票内容」；按 Enter，URL 更新为 `#main`，焦点落到 `main`。截图：`artifacts/review-keyboard-skip.png`。
