## 重点参考作品

### 1. 摸鱼纪元 95：视觉与情境参考

链接：https://traedemos.com/zh-CN/works/3143

作品把摸鱼做成 Windows 95 桌面里的小游戏。介绍说明有嵌套窗口、老板巡逻、怀疑度和老板键；作者称其为可离线运行的单文件 HTML。

已查看界面截图：青绿色桌面、灰色窗口、蓝色标题栏、凸起按钮、底部任务栏，复古语汇统一。

可借鉴：让视觉风格服务故事。熬夜投票器可以采用「深夜拨号聊天室」或「夜猫子 BBS」的外壳，把投票做成论坛调查，把结果做成站内公告。

取舍：主投票区域保持单窗口，避免多层弹窗遮挡选项；手机端采用纵向排版。

### 2. 投票吧：投票闭环参考

链接：https://traedemos.com/zh-CN/works/124

作品介绍称支持多个投票项目、每人一票，并自动生成扇形统计图，适用学校、企业和演出等场景。

可借鉴：选择选项 → 提交 → 确认成功 → 查看结果，形成清晰闭环。熬夜主题的选项较少，横向百分比条更便于比较，也更贴近早期网页调查的感觉。

限制：未验证实际投票流程及「每人一票」的实现机制。不能仅凭介绍推断其身份认证或防刷能力。

### 3. 白日梦制造机：轻量反馈参考

链接：https://traedemos.com/zh-CN/works/3144

作品从场景、角色、事件、情绪、时间五组词中组合一句白日梦，支持局部重抽和整体重抽。介绍强调无需登录，并使用霓虹卡片和打字机呈现。

可借鉴：一次操作立即得到有情绪价值的反馈。投票成功后可以生成「今晚夜猫子身份」与一句短评，例如「灵感值班员：再写一行就睡」。

取舍：随机反馈只影响文案，不影响票数和统计结果。

## 建议的 demo 方向（设计建议）

名称：**夜猫子 BBS · 今晚几点睡？**

核心体验控制在约 30 秒：

1. 进入带有像素月亮、站点公告、访客计数器样式的复古网页。
2. 回答「今晚准备几点睡？」：23 点前、23–24 点、0–1 点、1–2 点、2 点后。
3. 提交后显示自己的选择、百分比条及夜猫子身份短评。
4. 可选第二题「为什么还没睡？」：工作学习、游戏追剧、舍不得今天、就是睡不着。

视觉建议：深蓝夜空底色、米白内容面板、像素装饰、系统字体与等宽数字、凸起按钮、细边框分栏。正文优先保证中文可读性，动画提供关闭入口。

第一版优先完成投票、结果展示、本地记录和手机适配。访客计数器若仅为装饰或演示数据，应明确标识；本地存储只能记录当前浏览器的状态，公开多人投票需服务端保存和限制重复提交。

作品展示材料可按网站详情页结构准备：一句话简介、创作故事、三个亮点、使用场景，以及投票前后两张截图。
